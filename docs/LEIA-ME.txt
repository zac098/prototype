RDF - FERRAMENTAS DE PDF E RENOMEADOR DE FOLHAS - PACOTE PARA AVALIAÇÃO INSTITUCIONAL
Versão 4.1.0

FINALIDADE
Caixa de ferramentas de PDF que funciona offline (unir, dividir, comprimir, converter, girar, proteger, tarjar dados pessoais e outras), incluindo o renomeador de folhas de ponto, atestados e declarações.
Ferramenta interna de automacao documental com OCR, classificacao, revisao humana, visualizacao e exportacao de documentos.

ALTERACOES DESTA EDICAO (4.1.0)
- Abre bem mais rapido: o RDF instalado e uma pasta (nada e descompactado a cada abertura) e a tela inicial nao carrega mais o OCR.
- Download menor, sem bibliotecas que o RDF nao usa.
- Atualizacao dentro do app: aviso na tela inicial, download conferido (SHA-256) e instalacao em um clique.
- Visual mais limpo: icones proprios, nome e icone no topo de cada ferramenta, botao Voltar discreto.
- Correcoes: a janela podia fechar sozinha depois de varios "Imprimir com o RDF"; Configuracoes cortavam textos.
- Autoteste do executavel (RDF.exe --autoteste resultado.json) rodado no build de cada versao.
- Historico completo em docs/CHANGELOG.md; termos de uso em docs/termos; instalador e receita do build em packaging/.

INICIO RAPIDO
1. Instale Python 3.11 ou superior, as dependencias de requirements.txt e o Tesseract OCR.
2. Execute: python -m rdf (ou python rdf_app.py).
3. Execute os testes: python -m unittest discover -s tests -q
4. No Windows, use packaging\build_package.bat para gerar o instalador.
5. Detalhes para desenvolvimento (estrutura do código, lint, testes): README.md

IMPORTANTE
Este pacote e uma versao para avaliacao interna, nao homologada para uso com dados reais ou implantacao. A utilizacao em ambiente institucional depende de avaliacao e aprovacao das areas responsaveis.
